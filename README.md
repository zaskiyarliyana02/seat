# 🚆 SeatUp - Aman & Nyaman Bertransportasi

SeatUp adalah purwarupa website *e-ticketing* kereta api yang dirancang menggunakan prinsip *Human-Computer Interaction* (HCI) dengan fokus utama pada peningkatan keamanan penumpang perempuan[cite: 13].

## ✨ Fitur Utama
* **Gender-Based Seat:** Pemilihan kursi ramah gender dengan verifikasi identitas (E-KTP)[cite: 13].
* **Tombol Darurat (SOS):** Akses cepat untuk melapor insiden secara *real-time*[cite: 13].
* **Laporan Anonim:** Melaporkan tindak pelecehan tanpa mengungkap identitas pelapor[cite: 13].
* **Live Tracking & Stasiun Terdekat:** Pemetaan visual stasiun terdekat untuk mempermudah evakuasi[cite: 13].
* **Lost & Found:** Layanan pelaporan barang hilang dan temuan[cite: 13].
